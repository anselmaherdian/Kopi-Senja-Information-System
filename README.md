# Kopi-Senja-Information-System

## 1. Deskripsi
Sistem Informasi Kopi Senja merupakan aplikasi
berbasis web untuk membantu pengelolaan pemesanan,
pembayaran, persediaan bahan baku, dan laporan
penjualan pada tiga cabang Kopi Senja.

## 2. Aktor Sistem
- Pelanggan
- Kasir
- Barista
- Manajer Cabang
- Pemilik

## 3. Fitur Sistem
- Menampilkan daftar menu dan harga.
- Pemesanan menu secara online dan melalui kasir.
- Pembayaran tunai dan QRIS simulasi.
- Pengelolaan antrean pesanan.
- Pengurangan stok berdasarkan resep menu.
- Peringatan stok minimum.
- Laporan penjualan harian dan bulanan.

## 4. Teknologi
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- Git dan GitHub

## 5. Cara Menjalankan
1. Install dan jalankan XAMPP.
2. Aktifkan Apache dan MySQL.
3. Buat database dengan nama kopi_senja.
4. Import file database/kopi_senja.sql
   melalui phpMyAdmin.
5. Letakkan folder proyek di dalam htdocs.
6. Sesuaikan konfigurasi database pada
   src/config/database.php.
7. Buka browser dan akses:
   http://localhost/kopi-senja-information-system/

## 6. Tujuan
Membantu meningkatkan efektivitas operasional
Kopi Senja melalui sistem pemesanan dan
persediaan yang terintegrasi.
